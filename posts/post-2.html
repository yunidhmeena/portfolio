A Linux system monitor in a few hundred lines of Python

Python May 2025 · 4 min read

I wanted to answer a simple question without opening a browser: what is this machine actually doing right now? Windows and macOS ship polished graphs for this. On Linux, the answer is spread across top, df, free and whatever desktop widget you haven't configured. So I wrote my own.

system_monitoring is a small Python CLI tool. It samples CPU, memory and disk usage on an interval, prints them as simple bars, and optionally plots the history with matplotlib.

How it works

The whole data layer is the psutil library. Every sample is three calls:

import psutil

cpu = psutil.cpu_percent(interval=1)
mem = psutil.virtual_memory().percent
disk = psutil.disk_usage("/").percent

Everything else is presentation. argparse handles the CLI flags (--interval, --plot), a small loop keeps the terminal output aligned, and when plotting is on, the samples collect in a list and matplotlib draws the last minute of CPU history instead of just the current number.

What building it taught me

  • Reading OS state is cheap; presenting it well is the actual work.
  • CLI ergonomics matter. Sensible defaults, one flag per behavior, and a clean Ctrl+C exit took longer to get right than the data collection.
  • A README with install and usage instructions is part of the tool. Writing it forced me to make the flags make sense together.

What I'd add next

Alerts when a threshold is crossed, sampling history persisted between runs, and per-process CPU sorting are the obvious next steps. It's also the kind of tool that would be fun to expose through a tiny Flask or Express API later, which would tie it into the web stack I work in every day.
